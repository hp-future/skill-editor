# 任务映射

当用户请求不完全等同于接口名称时，优先用本表选择检索关键词。这里只提供检索方向，最终接口定义必须以 `api-wiki` 读取结果为准。

| 用户意图 | 检索关键词 | 常见目标接口 |
|---|---|---|
| 查询组合基本信息、组合信息、产品信息 | `组合基本信息`、`组合信息` | 组合基本信息查询 |
| 查询证券基本信息 | `证券基本信息` | 证券基本信息查询 |
| 查询交易费用、佣金、费率 | `交易费用设置`、`交易佣金设置`| 交易费用设置查询、交易佣金设置查询 |
| 查询股东账户、交易席位、产品关联信息 | `产品关联信息` | 产品关联信息查询 |
| 触发估值、资产估值核算 | `触发资产估值核算` | 触发资产估值核算 |
| 查询执行状态、轮询任务 | `执行状态检查` | 执行状态检查接口 |
| 查询执行日志、估值日志详情 | `获取执行日志` | 获取执行日志、估值日志详情 |
| 查询或执行数据导入 | `数据导入方案`、`文件检测`、`数据导入执行` | 数据导入方案查询、文件检测、导入执行 |
| 查询或触发清算 | `清算方案详情`、`资产数据清算` | 清算方案详情、触发资产数据清算 |
| 查询统计方案或触发统计分析 | `统计方案列表`、`统计分析处理` | 统计方案列表、触发统计分析处理 |

参数识别规则：

- 形如 `030106ZQ02B578869` 的长编码通常优先作为 `portCode` 或 `portCodeList` 候选，但必须结合接口定义确认字段类型。
- 日期缺失时，优先根据 api-wiki 接口定义处理：若日期为必填且文档说明未指定时默认当天，则使用当前会话日期；若日期为必填且文档没有默认当天或其他默认值，才向用户确认。
- 多接口链路必须明确前后依赖字段；依赖字段必须来自知识库响应说明或实际前序响应结构。
